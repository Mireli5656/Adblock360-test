# AdBlock360 Test

A modern open-source ad blocker and privacy testing tool built for GitHub Pages.

## Features

- Test ad blocking
- Test tracker blocking
- Privacy-focused design
- 100 real-world test domains
- Progress indicator
- Detailed test report
- Mobile responsive
- Fast and lightweight
- Open source

## How it works

AdBlock360 attempts to load advertising and tracking resources.

If your DNS, browser, or content blocker prevents those requests, the test marks them as blocked.

The final report includes:

- Overall Score
- Blocked Resources
- Ads Score
- Trackers Score
